# JavaScript Learning

My JavaScript practice, chapter by chapter — small files, each with commented worked examples.

## Chapter 3 — Operators (`operators.js`)

Real-life examples with `console.log` output:

- **Arithmetic** — total bill: price + 15% tax + delivery fee
- **Assignment** — `=` and `+=` (score updates)
- **Comparison** — `>=` (voting-age check)
- **Logical** — `&&` (exam entry: ticket + ID card), `||` (Sunday or holiday)
- **Ternary** — marks ≥ 80 ? scholarship : regular admission
- **Type** — `typeof` on the bill total

## Run it

With Node: `node operators.js` — or paste the file into a browser console.
